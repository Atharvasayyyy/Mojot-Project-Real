### Health Checks
```
GET /health (ML API)

GET /api/ml/model-info (Model info)
```

### Authentication
```
POST /api/auth/register (Create user)
```

### Predictions
```
POST /api/ml/predict/single (Single prediction)
POST /api/ml/predict/session/{id} (Analyze session)

```

### Batch
```
POST /api/ml/predict-batch (Multiple predictions)
```

After login, token auto-saves to variable:

Use in all protected requests:
```

```

**Token expires:** 24 hours
